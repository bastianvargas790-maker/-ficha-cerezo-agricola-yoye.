# Checklist de prueba · Calicatas

1. Iniciar sesión con un usuario autorizado.
2. Abrir Dashboard → Registro de calicatas.
3. Confirmar que aparecen los cuarteles reales.
4. Seleccionar un cuartel y completar una calicata real.
5. Registrar mediciones a 30/60/90 cm o las profundidades que correspondan.
6. Adjuntar al menos una fotografía.
7. Guardar y confirmar mensaje de éxito.
8. Abrir Ver historial y seleccionar el mismo cuartel.
9. Confirmar que aparece la evaluación, las lecturas, la fotografía y las gráficas.
10. Revisar que otro usuario sin permisos de edición no pueda modificar registros.

No usar datos ficticios en producción.
