# Prueba móvil recomendada

En iPhone:

1. Abrir la versión de prueba de la rama o una vista previa equivalente.
2. Iniciar sesión.
3. Entrar a Registro de calicatas.
4. Registrar una evaluación real de un cuartel.
5. Adjuntar una fotografía.
6. Guardar.
7. Abrir Historial y seleccionar el mismo cuartel.
8. Confirmar lecturas, imagen y gráficas.

Después de esta prueba se puede fusionar a producción.
